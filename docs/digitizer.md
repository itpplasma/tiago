# Digitiser stage

`tiago_digitizer_diagnostic::digitizer_diagnostic_t` maps any volt-level
recorded diagnostic to ADC counts, so a forward model reaches the recorded
digitiser data directly. It is a generic two's-complement ADC stage and
composes with any `profile_diagnostic_t` whose output is in volts, for
example `integrator_diagnostic_t` or a recorded ECE volt channel.
All examples and tests are synthetic.

## Forward model and parameters

For each channel *i* the digitiser converts an input voltage to counts by

```text
counts(i) = (volts(i) - voff(i)) / vres(i),
```

where `vres(i)` is the volts-per-count resolution and `voff(i)` the channel
offset. Both are calibration latents with a joint Gaussian prior
(`calibration_prior_t`) of `2*n_signals` parameters, ordered
`[vres_1..vres_n, voff_1..voff_n]`; `vres` means must be finite and
positive. Units: `volts` and `voff` in volts, `vres` in volts per count,
`counts` dimensionless. The decoder is the inverse map
`V = c*vres + voff` in `tiago_adc::adc_decode`.

`predict` returns the **expected** counts as reals without rounding, so the
JVP and VJP exist everywhere the inner model is differentiable; the partial
rows `d/dvolts`, `d/dvres`, `d/dvoff` are generated by FortSym in
`src/generated/digitizer_signal.f90`. Integer quantisation with clipping to
`[-2**(bits-1), 2**(bits-1)-1]` and a saturation flag is
`tiago_adc::adc_quantize(volts, vres, voff, bits, saturated)`.

## Quantisation noise

`adc_quantization_variance(vres) = vres**2/12` in V^2 models the rounding
error as uniform on one code step, following Widrow and Kollar,
*Quantization Noise*, Cambridge University Press, 2008, ch. 4. This holds
when the input spans many codes within a sample; a signal confined to a
few codes has correlated, non-uniform rounding and needs the actual signal
distribution instead. Add this variance to the propagated model covariance
in the likelihood; do not apply it twice to a channel that is already
differenced in counts.

## Verification

`tiago_digitizer` checks the decode/quantise round trip within half a code,
exact saturation at the code limits, the analytic count values and parameter
order through an integrator-wrapped probe, JVP/VJP against finite
differences and the adjoint identity, and the empirical 1/12 quantisation
variance over 1e5 samples. `tiago_digitizer_codegen` regenerates the kernel
and byte-compares it with the committed source; see
[gen/README.md](../gen/README.md) for the FortSym toolchain.
