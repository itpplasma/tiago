# Equilibrium medium for cold rays

`tiago_ece_state_medium::state_medium_t` connects the existing cold-ray tracer
to the existing real-space state sampler and kinetic B-spline profiles. The
medium owns a copy of the state, profiles and their latent vector `z`; keep
that copy unchanged between tracing and differentiation. Independent rays
share the immutable medium through `trace_cold_rays`, whose ray loop uses OpenMP.
No geometry, calibration or experimental measurements are built in.

Load a stellarator-symmetric VMEC wout with its vector coefficients enabled:

```fortran
call state%load(path, ierr, message, vector=.true.)
! Check ierr == 0 before using state.
allocate(medium%state, source=state)
medium%profiles = profiles
medium%z = z
call trace_cold_ray(medium, frequency, mode, initial, duration, ray, status)
```

`state` is `vmec_state_t`, `profiles` is `kinetic_profiles_t`, `z` contains
its standard-normal profile latents, and `medium` is `state_medium_t`.
Frequency, mode, launch and duration use the [cold-ray contract](ece-rays.md).
Check the returned status before reading the trace or its derivatives.
Existing scalar-only callers can omit `vector`; their parameter layout and
scalar magnitude interpolation are unchanged. A `vmecpp_state_t` snapshot can
instead be initialized with `init(coef,nfp,xm_nyq,xn_nyq,bmnc,bsupumnc,bsupvmnc)`;
all three field arrays use the full wout radial layout including the unused axis
column. Its optional vector spectra follow its existing `(coef,bmnc)` parameters.
The product Fourier geometry is converted with generated value/derivative rows
and delegated to the same wout vector sampler. No equilibrium is duplicated.

## Vector field and spatial derivatives

`real_space_state_t%vector_jets(u,jet,status)` extends the existing state
interface at labels `u=(rho,theta,phi)`. It supplies Cartesian position, its
first and second label derivatives, the Cartesian magnetic field and its first
and second label derivatives, plus fixed-label parameter rows for position,
its label gradient, field and its label gradient. Providers without this
extension return a nonzero status. There is still one inverse-map method:
`real_space_state_t%locate`.

VMEC's vector field is reconstructed as
`B = B^theta * X_theta + B^phi * X_phi`, using `bsupumnc` and `bsupvmnc`
on the half radial grid and the existing R/Z geometry on the full grid.
The toroidal angle is the physical angle; `xn` already includes the field
period factor. The coefficients and grids follow the
[VMEC++ wout convention](https://proximafusion.github.io/vmecpp/tutorials/postprocessing_wout.html).
These coefficients supply the internal total field; no exterior sheet-current
field or guessed direction enters the medium. The separately interpolated
scalar `bmnc` remains the existing scalar diagnostic representation; at finite
radial/angular resolution its magnitude can differ from that of this vector.

`tiago_state_sampler::sample_medium` takes a Cartesian point in metres and
returns the [ray medium arrays](ece-rays.md): B in tesla, electron density in
m^-3, first derivatives per metre, second derivatives per metre squared, and
parameter rows of the values and first spatial derivatives. Density uses the
existing log B-spline, correlated Gaussian-process prior map and exponential
scrape-off continuation. Other kinetic latents retain their existing ordering
and have zero direct density rows. For the vector-enabled wout state, the
parameter vector is the old `(rmnc,zmns,bmnc)` vector followed by `bsupumnc`,
then `bsupvmnc`, each flattened in Fortran order; profile latents follow all
state parameters. These are provider output coefficients, not new independently
calibrated parameters: compose their rows with the provider's own derivatives.

The inverse-function rule transforms label derivatives to spatial derivatives.
For scalar `f`, inverse Jacobian `A=(X_u)^-1` and spatial gradient `g`,
`g=A^T f_u` and `f_xx=A^T (f_uu-sum_i g_i X_i,uu) A`.
The parameter rows include label displacement at fixed Cartesian position.
The Fourier geometry, Hermite higher derivatives, contravariant contraction,
density jets and inverse-map rows are generated by FortSym from
`gen/gen_ece_geometry.f90`, committed with their generated Fortran.

## Composing derivatives with a moving ray

`medium_sample_jvp` differentiates sampled values **and their spatial
gradients** with respect to position and the combined state/profile vector;
`medium_sample_vjp` returns the transpose with overwritten output seeds.
Spatial Hessians are coefficients of this derivative, not an output whose
third spatial or parameter derivatives are exposed by this API.

The cold-ray JVP (Jacobian-vector product) and VJP (its transpose) use these
same medium rows to differentiate the accepted integration schedule, including
the path. To sample profiles at the endpoint, pass the first three components
of `cold_ray_jvp` as `xdot` to `medium_sample_jvp`, together with the same
parameter tangent. In reverse, add the sampled position cotangent to the ray's
endpoint seed and add its direct parameter cotangent to `cold_ray_vjp`'s
parameter result. This retains profile changes caused by ray displacement;
freezing the sample position would omit them. Duration, adaptive decisions and
terminal events retain the tracer's existing inactive-input conventions.
This adapter does not integrate opacity or transfer along the trajectory.

## Verification and domain

`tiago_ece_geometry` checks an analytic circular chart with the divergence-free
field `B=0.3*(-y,x,0)` T (coordinates in metres) and a known exponential
flux profile; spatial derivatives; every state/profile parameter column;
value/gradient transpose identities; fully oblique O/X path derivatives;
profiles sampled on moving endpoints; straight vacuum rays; and invalid points.
Nonzero poloidal field and toroidal Fourier modes exercise mixed derivatives.
`tiago_ece_geometry_vmecpp` repeats the analytic, every-column and moving-path
checks on the product-basis snapshot, including all four R/Z coefficient blocks.
`tiago_ece_geometry_vmec` also checks spatial derivatives and short O/X traces
on the existing pinned, published VMEC fixture. The analytic chart is a
sampler control, not a newly solved force-balanced equilibrium.

`tiago_ece_geometry_limits` reproduces the ordinary-mode linear slab turning
trajectory and parabolic-cylinder harmonic orbit used in the cold-ray tests
(Stix, *Waves in Plasmas*, 1992, chapter 1). A circular VMEC chart supplies
the field and density coordinates. Log B-spline interpolation approximates
these densities: refinement from 65 to 129 breakpoints reduces whole-path
position/index errors from about 1e-6 to below 6e-8 m/dimensionless.
`tiago_ece_geometry_codegen` checks exact regeneration when
`TIAGO_FORTSYM_BUILD` is configured; `benchmark_ece_geometry` measures 256
independent synthetic rays with the full medium derivative rows.

The inherited Hermite interpolation is C1: Hessians are piecewise values,
with the right radial interval selected at interior knots. Do not claim a
unique Hessian or gradient sensitivity at a knot with a curvature jump.
The magnetic axis is a singular label chart; failed inversions, unsupported
providers and points beyond `rho_chart` return nonfinite medium data and are
rejected by the ray tracer. Extrapolation just outside the last surface is the
existing mathematical continuation, not a verified scrape-off magnetic model.
The stellarator-symmetric wout state and VMEC++ geometry-state snapshot both
implement vector jets. The snapshot caller must supply the contravariant
spectra and refresh them after a solve. Contracting their output cotangents
through VMEC++'s implicit equilibrium adjoint is outside this sampler; that
full equilibrium-input chain remains unverified.
Neither experimental validation, equilibrium-input derivatives, relativistic
opacity nor a complete recorded radiometer likelihood is verified here.
